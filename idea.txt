# MASTER PROJECT BRIEF – AI-BASED WEB APPLICATION FIREWALL

## 1. Project Overview

I am developing a B.Tech final-year capstone project in Artificial Intelligence and Machine Learning.

**Project Title:** AI-Based Web Application Firewall for SQL Injection and XSS Detection.

**Primary Dataset:** CSIC 2010 HTTP Dataset.

**Domain:** Artificial Intelligence, Machine Learning, Deep Learning and Cybersecurity.

The objective is to develop an intelligent Web Application Firewall (WAF) that can inspect incoming HTTP requests, identify malicious requests, particularly SQL Injection (SQLi) and Cross-Site Scripting (XSS), and prevent malicious requests from reaching a protected web application.

This is not just a machine learning classification notebook or a dashboard. It must ultimately become a functional, experimentally evaluated and deployable AI-powered Web Application Firewall.

---

## 2. Problem Statement

Modern web applications receive HTTP requests from thousands of users. Attackers can manipulate these requests to exploit application vulnerabilities.

Two major attacks that our project focuses on are:

### A. SQL Injection (SQLi)

Attackers insert malicious SQL commands into input fields or HTTP parameters to manipulate database queries.

Example:

Normal request:
`/search?q=laptop`

Malicious request:
`/search?q=' OR 1=1 --`

Potential consequences:
- Unauthorized database access.
- Authentication bypass.
- Data leakage.
- Database manipulation.

### B. Cross-Site Scripting (XSS)

Attackers inject malicious JavaScript or HTML into web application inputs, which may execute in other users' browsers.

Example:

`<script>alert('XSS')</script>`

Potential consequences:
- Session compromise.
- Unauthorized browser actions.
- Phishing.
- Website content manipulation.

### Limitations of Traditional WAFs

Traditional Web Application Firewalls mainly depend on predefined signatures and rules.

For example:
- Detecting UNION SELECT.
- Detecting script tags.
- Detecting suspicious SQL keywords.
- Detecting malicious HTML patterns.

These rules are useful but may fail against modified, encoded or obfuscated attack patterns. Poorly configured rules can also block legitimate requests.

### Our Proposed Solution

Develop an AI-powered WAF that learns patterns from HTTP traffic using Machine Learning and Deep Learning.

The system will compare:
1. Traditional rule-based detection.
2. Machine Learning detection.
3. Deep Learning detection.

It will also incorporate Explainable AI to understand why a request is classified as malicious.

The best experimentally validated model will be integrated into a working WAF application.
